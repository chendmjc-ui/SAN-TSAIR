# 三才實業專案 — GCP 免費版 (e2-micro) 負載力評估報告
> 建立日期：2026-05-27 11:23

## ❓ 問題：GCP 終身免費版足夠我使用嗎？
**結論：絕對足夠，但需要加上「防崩潰機制 (Swap)」。**

對於三才實業目前的數位轉型需求（接收客戶詢價表單、發送 LINE 通知、未來可能串接 Google 試算表或發送 Email），GCP 免費版的規格完全能勝任。以下為詳細評估：

---

## 📊 規格與負載分析

### 1. 記憶體 (RAM)：1 GB (這是最大的瓶頸)
* **挑戰**：n8n 是基於 Node.js 開發的系統，啟動時大約需要 300~500 MB 的記憶體。如果在同一秒鐘內有大量客戶同時送出表單，或是您在 n8n 中處理龐大的 JSON / 圖片檔案，1GB 的記憶體極有可能發生 **OOM (Out Of Memory) 記憶體不足**，導致主機當機。
* **解法 (我們已寫入腳本)**：我們會在自動化安裝指令中，為機器切出 **2GB 的虛擬記憶體 (Swap 空間)**。當實體記憶體不夠時，會暫時借用硬碟空間來運算，徹底解決小機器跑 n8n 容易當機的通病。

### 2. 處理器 (CPU)：e2-micro (2 個共用核心)
* **評估**：非常夠用。三才實業的工作流（Webhook 接單 -> 傳 LINE）屬於極低耗能的網路請求，幾乎不佔用 CPU 運算能力。

### 3. 儲存空間：30 GB 標準硬碟
* **評估**：綽綽有餘。安裝作業系統、Docker 與 n8n 後，大約只佔用 4~5 GB，您還有 20 多 GB 的空間可以儲存 n8n 的執行紀錄與資料庫。

### 4. 網路流量：每月 1 GB 免費對外流量
* **評估**：完全夠用。傳送 JSON 文字或 LINE 通知的流量極小（通常一次請求不到 0.01 MB）。就算未來流量超標，每超出的 1 GB 也僅需支付幾塊錢台幣。

## 🚀 專屬最佳化設定 (已整合至安裝腳本)
為確保您的免費版主機能達到「企業級穩定度」，我們為您客製化了以下 n8n 環境變數：
* `EXECUTIONS_DATA_PRUNE=true`：自動清除超過 14 天的執行紀錄，避免長期運行後硬碟被塞滿。
* `EXECUTIONS_PROCESS=main`：強制 n8n 在主執行緒運作，不額外開啟消耗記憶體的子程序，這是 1GB 記憶體機器的必備設定。
